# Bundled fonts

These are locally bundled **Latin subsets** (woff2) of open-source fonts published on Google Fonts:

| File | Family | Source |
| --- | --- | --- |
| `instrument-sans-latin.woff2` | Instrument Sans 400–700 | <https://fonts.google.com/specimen/Instrument+Sans> |
| `baskervville-latin.woff2` | Baskervville 400 | <https://fonts.google.com/specimen/Baskervville> |

Both are licensed under the **SIL Open Font License, Version 1.1**
(<https://openfontlicense.org/>). The full license text and copyright notices are
available from the upstream repositories under `ofl/<family>/OFL.txt`:
<https://github.com/google/fonts/tree/main/ofl>.

Only the `latin` unicode subset is included. Chinese text is served by the system
UI font (Microsoft YaHei UI / PingFang SC) as declared in `style.css`.
