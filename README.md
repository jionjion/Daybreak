# Daybreak 晨屿 1.1.1

晨屿是自用的 Chrome / Edge 新标签页扩展。首页保留了 1.0 的工作台，喜欢 Infinity 图标布局可以打开「个人设置 → 首页布局 → 经典图标」。另有只显示壁纸、时钟和搜索的极简模式。

## 安装和升级

1. 在 Chrome 打开 `chrome://extensions`，Edge 使用 `edge://extensions`。
2. 首次安装时，开启「开发者模式」，点击「加载已解压的扩展程序」，选择含有 `manifest.json` 的 `W:\Daybreak`。已从这个目录加载晨屿的用户，直接点击晨屿卡片的「重新加载」。
3. 新开一个标签页。如果还显示 Infinity，先在扩展管理页暂时停用 Infinity。要在启动浏览器时也打开晨屿，在浏览器的启动设置中选择「打开新标签页」。
4. 将晨屿固定到浏览器工具栏，以后浏览网页时点击图标即可收藏。更新时继续使用同一目录和浏览器配置，可保留原有资料。

## 从 Infinity 导入

在 Infinity Pro 打开「我的 → 导出备份数据」，取得 `.infinity` 文件。然后在晨屿打开「个人设置 → 备份与迁移 → 选择备份文件」。预览会显示网页、笔记、待办数量，以及需要重新选择的项目。默认「补充记录」会保留晨屿里已有的同名数据。选择覆盖前，可先创建一个本机还原点。

## 日常使用

| 入口 | 常用操作 |
| --- | --- |
| 今日 | 网页、图片、新闻、视频、地图分类根据引擎显示。按 `/` 聚焦搜索框。可以添加使用 `%s` 占位的引擎，选择当前页或新标签页打开。开启本地搜索建议后可用方向键和回车选择。 |
| 网页收藏 | 工具栏可收藏当前网页并使用网站图标。首页支持分页、文件夹、打开组内全部网页，以及自定义图标。从首页「管理」进入整理模式，拖到另一个图标中央可建文件夹，拖到边缘可排序；也可用按钮调整顺序。首页「添加」可以手动输入网址，也可进入分类目录，也可从浏览器书签中挑选。 |
| 书签和历史 | 使用当前浏览器配置中的数据。书签可以新建、编辑、移动和按文件夹管理。历史记录支持搜索、分页、时间范围和确认后清除。 |
| 待办 | 回车添加，可改文字、设置提醒、筛选、排序和清除已完成项目。桌面通知需要授权，系统通知设置也会影响横幅显示。 |
| 笔记 | 自动保存多篇笔记，支持独立标题、置顶、搜索、排序、插图、加粗、链接和图文预览。 |
| 天气 | 支持多城市、摄氏与华氏、逐日预报、湿度、气压和风。以数据源返回的项目为准。断网时显示上次缓存和更新时间。 |
| 壁纸 | 支持纯色、内置背景、本地相册、多图导入、顺序或随机轮换、Bing 每日壁纸和下载当前图片。可调整遮罩和模糊。 |
| 工具 | 按需启用扩展管理、常用网站与 Gmail 未读提醒。扩展管理作用于当前浏览器。Gmail 使用已登录且支持 Inbox Feed 的 Google Workspace 收件箱。 |
| AI | 「AI 搜索」将问题交给 Perplexity 搜索。「打开 AI 对话」可连接本机 Ollama，在模型列表中选择后开始多轮会话，支持停止、重试和恢复会话。 |
| 个人设置 | 可切换首页模式、设置图标行列和外观、开关小工具、顶部书签或最常访问栏，也可设置各类链接的打开方式。 |

### 使用本机 AI

本机 Ollama 需要有一个已下载的模型。点击「AI 对话 → 连接」后，晨屿会申请访问 `127.0.0.1:11434`。如果服务返回 403，界面会显示本扩展的具体来源，可按提示加入 Ollama 允许来源后重启服务。[Ollama 浏览器扩展配置](https://docs.ollama.com/faq#how-can-i-allow-additional-web-origins-to-access-ollama)

### 备份与跨设备使用

晨屿资料默认保存在当前浏览器配置中。可以导出 JSON，或在本机创建手动、每日自动还原点，两种各保留最近三份。卸载扩展会清理本地数据，导出的备份可另行保存。浏览器书签和历史由浏览器自身管理。

有自己的 WebDAV 服务时，在两台设备的「个人设置 → 跨设备备份」填写同一个 JSON 文件的 HTTPS 地址。一台上传，另一台预览并合并。覆盖已有远程文件要求服务器提供强 ETag，以便发现另一台设备的改动。用户名、密码或令牌只在当前页面中使用。

天气查询使用 Open-Meteo 或 wttr.in，Bing 每日壁纸、Gmail、AI 模型和 WebDAV 均按对应功能使用。内置湖景已保存在扩展目录内。[湖景来源](https://images.unsplash.com/photo-1470770841072-f978cf4d019e)

更多细节见同目录的《Infinity Pro 功能对照》。
