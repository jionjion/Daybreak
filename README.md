# Daybreak 晨屿 1.1.1

晨屿是自用的 Chrome / Edge 新标签页扩展。首页展示浏览器书签、时钟和搜索，喜欢 Infinity 图标布局可以打开「个人设置 → 首页布局 → 经典图标」。另有只显示壁纸、时钟和搜索的极简模式。

## 安装和升级

1. 在 Chrome 打开 `chrome://extensions`，Edge 使用 `edge://extensions`。
2. 首次安装时，开启「开发者模式」，点击「加载已解压的扩展程序」，选择含有 `manifest.json` 的 `W:\Daybreak`。已从这个目录加载晨屿的用户，直接点击晨屿卡片的「重新加载」。
3. 新开一个标签页。如果还显示 Infinity，先在扩展管理页暂时停用 Infinity。要在启动浏览器时也打开晨屿，在浏览器的启动设置中选择「打开新标签页」。
4. 将晨屿固定到浏览器工具栏，以后点击图标即可打开晨屿。更新时继续使用同一目录和浏览器配置，可保留原有资料。

## 日常使用

| 入口 | 常用操作 |
| --- | --- |
| 今日 | 网页、图片、新闻、视频、地图分类根据引擎显示。可以添加使用 `%s` 占位的引擎，选择当前页或新标签页打开。开启本地搜索建议后可用方向键和回车选择。 |
| 首页书签 | 直接展示浏览器「书签栏」和「其他书签」里的网页，按 Ctrl+D 收藏后自动出现。全部书签一次展示、不分页，用标签页切换文件夹，以「小图标 + 站点名」的横向链接列表排列；文件夹与书签栏、其他书签排成标签，点击标签切换下方内容，不需要跳转页面。只读展示，不需要在晨屿里维护第二份收藏。 |
| 书签 | 使用当前浏览器配置中的数据。书签可以新建、编辑、移动和按文件夹管理。 |
| 天气 | 主页不显示天气；城市选择、摄氏/华氏、逐日预报、湿度、风和 API Key 都在「个人设置 → 天气服务」中管理，支持离线缓存。使用高德开放平台，城市搜索与天气查询共用同一个 Web 服务 Key。 |
| 壁纸 | 新装默认使用 Bing 每日壁纸；也可选纯色、内置背景、本地相册、多图导入、顺序或随机轮换和下载当前图片。可调整遮罩和模糊。 |
| 个人设置 | 可切换主题配色（预设色板或自定义取色）、首页模式、设置图标大小和外观、开关天气工具、顶部书签或最常访问栏，也可设置各类链接的打开方式。 |

### 数据保存

晨屿资料默认保存在当前浏览器配置中，卸载扩展会清理本地数据。浏览器书签由浏览器自身管理。

天气查询使用高德开放平台，Bing 每日壁纸由 Bing 提供。内置湖景已保存在扩展目录内。[湖景来源](https://images.unsplash.com/photo-1470770841072-f978cf4d019e)

更多细节见同目录的《Infinity Pro 功能对照》。
