# Daybreak 晨屿 1.1.1

晨屿是自用的 Chrome / Edge 新标签页扩展。首页保留了 1.0 的工作台，喜欢 Infinity 图标布局可以打开「个人设置 → 首页布局 → 经典图标」。另有只显示壁纸、时钟和搜索的极简模式。

## 安装和升级

1. 在 Chrome 打开 `chrome://extensions`，Edge 使用 `edge://extensions`。
2. 首次安装时，开启「开发者模式」，点击「加载已解压的扩展程序」，选择含有 `manifest.json` 的 `W:\Daybreak`。已从这个目录加载晨屿的用户，直接点击晨屿卡片的「重新加载」。
3. 新开一个标签页。如果还显示 Infinity，先在扩展管理页暂时停用 Infinity。要在启动浏览器时也打开晨屿，在浏览器的启动设置中选择「打开新标签页」。
4. 将晨屿固定到浏览器工具栏，以后浏览网页时点击图标即可收藏。更新时继续使用同一目录和浏览器配置，可保留原有资料。

## 日常使用

| 入口 | 常用操作 |
| --- | --- |
| 今日 | 网页、图片、新闻、视频、地图分类根据引擎显示。按 `/` 聚焦搜索框。可以添加使用 `%s` 占位的引擎，选择当前页或新标签页打开。开启本地搜索建议后可用方向键和回车选择。 |
| 网页收藏 | 工具栏可收藏当前网页并使用网站图标。首页支持分页、文件夹、打开组内全部网页，以及自定义图标。从首页「管理」进入整理模式，拖到另一个图标中央可建文件夹，拖到边缘可排序；也可用按钮调整顺序。首页「添加」可以手动输入网址，也可进入分类目录，也可从浏览器书签中挑选。 |
| 书签和历史 | 使用当前浏览器配置中的数据。书签可以新建、编辑、移动和按文件夹管理。历史记录支持搜索、分页、时间范围和确认后清除。 |
| 待办 | 回车添加，可改文字、设置提醒、筛选、排序和清除已完成项目。桌面通知需要授权，系统通知设置也会影响横幅显示。 |
| 笔记 | 自动保存多篇笔记，支持独立标题、置顶、搜索、排序、插图、加粗、链接和图文预览。 |
| 天气 | 支持多城市、摄氏与华氏、逐日预报、湿度、气压和风。使用和风天气，需在「个人设置 → 天气服务」填写 API Host 和 API Key。断网时显示上次缓存和更新时间。 |
| 壁纸 | 新装默认使用 Bing 每日壁纸；也可选纯色、内置背景、本地相册、多图导入、顺序或随机轮换和下载当前图片。可调整遮罩和模糊。 |
| 个人设置 | 可切换主题配色（预设色板或自定义取色）、首页模式、设置图标行列和外观、开关小工具、顶部书签或最常访问栏，也可设置各类链接的打开方式。 |

### 数据保存

晨屿资料默认保存在当前浏览器配置中，卸载扩展会清理本地数据。浏览器书签和历史由浏览器自身管理。

天气查询使用和风天气，Bing 每日壁纸由 Bing 提供。内置湖景已保存在扩展目录内。[湖景来源](https://images.unsplash.com/photo-1470770841072-f978cf4d019e)
